# Competency Questions

HNEO should answer questions such as:

1. Which people simultaneously held roles in government, private intelligence, foundations, or political organizations during a specified interval?
2. Which organizations received funds through an intermediary rather than directly from a donor?
3. Which claims about a given operation are supported and contradicted by independent sources?
4. Which propositions remain unresolved?
5. Which actors recur across otherwise distinct historical episodes?
6. Which apparent connections disappear when a temporal filter is applied?
7. Which people are central across multiple relationship layers rather than one generic association graph?
8. Which source first introduced a disputed proposition?
9. Which later sources copied rather than independently corroborated an allegation?
10. Which theories share component propositions?
11. Which operational relationships are documented independently of ideological alignment?
12. Which organizations acted as proprietaries, fronts, conduits, contractors, or autonomous allies during different periods?
13. Which claims of institutional capture are supported by lower-level evidence such as appointments, funding dependence, or operational direction?
14. Which funding chains connect donors, foundations, intermediaries, operations, and beneficiaries?
15. Which nodes are merely mentioned together versus actually participating in a common event?
