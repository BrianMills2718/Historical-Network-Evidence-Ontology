# Query Cookbook

The `queries/` directory includes examples for documented propositions, unresolved propositions, contradictory claims, operation participants, and theory comparison.

## Person-organization affiliation

Project RoleHolding and Membership instances into a bipartite graph.

## Funding chains

Traverse FinancialTransfer and FundingArrangement events rather than generic edges.

## Evidence-filtered graph

Construct an analytic network containing only propositions assessed at or above a selected status.

## Temporal slice

Include only relationships whose intervals intersect the requested time range.

## Source worldview

For a source or author, select propositions they hold true and compare set intersections/differences with another source.
