# Epistemology

HNEO treats epistemic structure as first-class data.

## Proposition versus claim

A **proposition** is the content that can be accepted, rejected, or left unresolved.

A **claim** records an agent or source taking an epistemic position toward a proposition.

Example:

- Proposition: "Organization X participated in activity Y."
- Claim A: Witness W asserts the proposition is true.
- Claim B: Agency report R treats the proposition as unverified.
- Project Assessment C: HNEO researchers mark it unresolved.

These records can coexist.

## Evidence

Evidence is not represented as a scalar confidence number. Important dimensions include:

- authenticity
- source directness
- temporal proximity
- source independence
- external corroboration
- specificity
- internal consistency
- chain of custody
- institutional access
- possible motive to misrepresent

## Assessment vocabulary

Suggested project statuses:

- NotAssessed
- Documented
- StronglySupported
- Supported
- Plausible
- Unresolved
- Disputed
- WeaklySupported
- Contradicted
- Disconfirmed

These statuses describe the project assessment at a time; they are not universal truth values.

## Contradiction

Contradictory claims are expected.

HNEO never requires a contested proposition to be asserted directly in the master world graph. Instead, sources assert proposition graphs. Project assessments evaluate those propositions independently.

## Theory decomposition

Large interpretations such as "the Octopus" are represented as theories containing component propositions. Individual propositions can receive different evidentiary assessments. The theory is therefore decomposable and falsifiable.
