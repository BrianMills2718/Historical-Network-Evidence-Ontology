# Worked Historical Network Example

`historical-network.trig` is a synthetic demonstration dataset showing how HNEO represents the types of historical material discussed during initial design.

It is not intended as an exhaustive historical database.

The example includes:
- Operation Underworld
- CIA-Mafia anti-Castro activity
- The Company / Bluegrass Conspiracy
- Black Tuna
- Watergate
- Moorer-Radford
- Cultural Cold War institutions
- anti-communist labor networks
- World Anti-Communist League milieu
- CAT/Air America proprietary patterns
- Iran-Contra and the Enterprise
- private Contra fundraising
- BCCI
- PROMIS / INSLAW / Wackenhut-Cabazon allegations
- institutional capture hypotheses
- Hougan, Casolaro, Brussell, and Emory-style theories as theories rather than asserted umbrella organizations

Some proposition pairs are deliberately contradictory to demonstrate that the graph can preserve disagreement without collapsing it into a single asserted truth.
